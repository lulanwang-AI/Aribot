🧠 AI Integration Example (Workflow)
User uploads scan in Patient Detail Page.
AI auto-detects 3 targets (e.g., lymph node, lung mass).
Results populate on the sidebar.
User can label, annotate, and export the report.
Back on this patient dashboard, an icon appears next to the patient’s name:
✅ if AI analysis complete
⚠️ if pending
